# EasyWar 路线图（ROADMAP）v1

> 原则：每个里程碑结束都是「能跑、能玩」的状态；先验证规则，再验证手感，再包装。

## M1 机制骨架 —— 验证「规则有没有跑通」 ✅（2026-08-05 完成）

- [x] Bevy 工程脚手架（桌面原生，不引入原生专属 API）
- [x] 逻辑层独立模块：网格地图、阵营、据点、地块、小队、兵流（不依赖渲染）
- [x] TOML 地图/词库加载（serde + 自定义解析；热重载留待 M2）
- [x] H 型地图渲染（色块 + 文字，零美术资源）
- [x] 据点产兵、驻军无上限、产能与关联地块挂钩
- [x] 派兵意图：兵流建立 / 改道 / 停止 / 增援（首版为拖拽，后续已拆分桌面与触屏输入）
- [x] 小队行军：最短路径（等长优先己方格）、逐格移动
- [x] 战斗：双向抵扣（小队↔地块、小队↔小队、小队↔据点驻军）
- [x] 占领与回防、兵流终止规则（地块回兵、据点续灌）
- [x] 胜负判定（据点全失即负、全占即胜）
- [x] AI 木头人（只产兵不出门），供玩家打靶验证机制
- [x] 逻辑层单元测试 7/7 + 无头冒烟模式（`--headless`）
