- [x] TOML 地图/词库加载（serde + 自定义解析；热重载留待 M2）

- [x] 据点产兵、驻军无上限、产能与关联地块挂钩
- [x] 派兵意图：兵流建立 / 改道 / 停止 / 增援（首版为拖拽，后续已拆分桌面与触屏输入）

- [x] 战斗：双向抵扣（小队↔地块、小队↔小队、小队↔据点驻军）
- [x] 占领与回防、兵流终止规则（地块回兵、据点续灌）
- [x] 胜负判定（据点全失即负、全占即胜）

- [x] 逻辑层单元测试 7/7 + 无头冒烟模式（`--headless`）
