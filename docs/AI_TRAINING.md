# EasyWar 1v1 神经网络 AI 训练

## 1. 当前目标与边界

本阶段建立可运行、可复现的 1v1 训练与游戏内推理竖切，让神经网络只通过玩家可见信息和玩家合法动作对战多难度规则 AI 或冻结的历史神经网络模型。H 图已退出训练，只保留为不产生梯度的环境接口夹具。3~6 人、联盟和非对称玩法仍不在本阶段范围内。

训练结果评价 AI，不替代地图评审。地图是否有趣仍需真人试玩验证多样策略、反制可读性和长期重复游玩体验。

## 2. 架构

- Rust `easywar-logic::rl`：加载真实地图与规则，执行权威 `SimTick`，输出固定观察、合法动作掩码、奖励和终局分类；
- Rust `easywar-rl-python`：通过 PyO3 暴露批量环境，并以稳定下标顺序并行推进多个环境；
- Python/PyTorch：CNN 编码空间状态，以“源据点 × 目标格”组合动作头训练策略和值函数；
- 外部模型对手：Rust 同一步接收双方玩家级动作，并把学习者先提交、对手先提交作为独立变体；Python 将冻结检查点稳定分配到各环境；
- 本地环境：`uv` 固定 Python 3.12 和依赖锁文件，Apple Silicon 使用 MPS，NVIDIA 环境优先 CUDA。

Rust 目前复用 ECS 参考实现，保证规则一致性。后续只有在逐步轨迹对齐测试存在时，才允许抽取更快的纯数据模拟内核。

## 3. 观察、动作与奖励

观察为 `17 × 13 × 17` 的玩家视角通道，覆盖地图几何、地块类型、己方/敌方/中立归属、驻军、关联地块、小队分布和双方兵流。地图外区域补零；据点槽位固定为 16 个。

动作总数为 3553：

- 1 个等待动作；
- `16 × 221` 个“从据点槽位向固定网格目标派兵”动作；
- 16 个停止兵流动作。

每步提供合法动作掩码。动作目标按固定 17 列观察网格编码，不得按具体地图宽度编码。终局胜负奖励占主导，领地与兵力势能差只提供小幅塑形。

终局必须分类为：

- `Won` / `Lost`：正常胜负；
- `Stalemate`：长时间没有领地或兵流目标进展；
- `CycleDetected`：动态状态重复且仍有运动；
- `BudgetExceeded`：触发工程保险预算。

工程预算不是玩法时间上限。报告不得把后三类折叠为超时或从分母中静默删除。

## 4. 训练课程

1. 非训练接口回归：H 图只验证观察、动作和批量环境能否运行，不生成训练样本；
2. 规则模仿：使用 normal 决策参数的确定性规则老师生成无作弊标签，非等待指令加权，并用 DAgger 混入模型动作以覆盖错误后状态；
3. 主要训练：当前只混合双线梯形与编织双环；规则对手按 easy、normal、hard 与地图、席位正交取样，再进入 PPO；双层三角 1v1 投影暂停训练，只保留地图资产与静态回归；
4. 历史对手课程：从已通过训练图门禁的冻结检查点中取样，按“地图 × 出生席位 × 提交顺序”正交覆盖；独立规则 AI 验证仍作为稳定锚点；
5. 留出考试：外环加横梁完全不参与梯度更新或模型挑选。

历史 H 图训练结果只保留为早期工程记录，不再参与当前模型比较。当前代码会拒绝 `warmup` 训练阶段，也会拒绝把 H 图解析为训练自同构。

## 5. 运行

```bash
cd training
uv sync --python 3.12

uv run python train_ppo.py \
  --phase main --rule-opponents easy normal hard --teacher normal \
  --initialize-from checkpoints/main-stage2-low-lr-best.pt \
  --anchor-checkpoint checkpoints/main-stage2-low-lr-best.pt \
  --anchor-kl-coef 0.05 \
  --num-envs 24 --imitation-updates 0 --learning-rate 3e-5 \
  --updates 20 --threads 14 \
  --validation-every 5 --validation-episodes 16 \
  --validation-opponents easy normal hard \
  --minimum-validation-completion 0.8 --minimum-validation-win-rate 0.5 \
  --checkpoint checkpoints/main-stage1.pt \
  --best-checkpoint checkpoints/main-stage1-best.pt \
  --report runs/main-stage1.jsonl
```

检查点恢复与跨课程初始化使用不同语义：`--resume` 恢复优化器、累计更新数和后续环境种子；`--initialize-from` 只继承模型权重。`--anchor-checkpoint` 另行加载冻结旧模型，用 `KL(旧策略 || 当前策略)` 同时约束模仿和 PPO；锚点路径与系数属于恢复训练不可变状态。验证采用与训练不重叠的固定种子，并要求每个“训练图 × easy/normal/hard”因子分别达到最低正常完赛率和全样本胜率。切换课程时先保存初始验证模型，后续训练退化时不会覆盖它。

历史模型对手课程示例：

```bash
uv run python train_ppo.py \
  --phase main --rule-opponents normal \
  --historical-opponent checkpoints/main-stage1-best.pt checkpoints/main-stage2-low-lr-best.pt \
  --initialize-from checkpoints/main-stage2-low-lr-best.pt \
  --anchor-checkpoint checkpoints/main-stage2-low-lr-best.pt --anchor-kl-coef 0.05 \
  --num-envs 24 --updates 20 --learning-rate 3e-5 \
  --validation-every 5 --validation-opponents easy normal hard \
  --checkpoint checkpoints/historical-pool.pt \
  --best-checkpoint checkpoints/historical-pool-best.pt
```

历史池路径会写入检查点；`--resume` 必须提供相同清单和相同规则锚点配置。

评测时可以同时保存每种已出现终局的一局代表回放，并立即从头复验：

```bash
uv run python evaluate.py checkpoints/main-best.pt \
  --map ring_chord_1v1.toml --opponent normal --episodes 100 \
  --json runs/heldout.json --replays runs/heldout-replays.json

uv run python replay.py runs/heldout-replays.json
```

## 6. 当前基线证据

在 Apple M4 Pro、14 工作线程上，64 个 H 图环境连续推进 64 次决策的实测吞吐为约 6200 游戏秒/墙钟秒；单线程约 1153 游戏秒/墙钟秒。线程数变化的逐环境结果由确定性测试锁定。

早期曾用 H 图做 1500 次 DAgger 热身；该模型对 easy 的 H 图为 26 胜、5 负、1 次循环，但在外环横梁仅 5 局取胜，另有 14 次循环和 13 次僵局。该结果是 H 图退出训练的直接证据：它只让模型记住低策略拓扑，不能形成可接受的跨图泛化。

第一轮主课程在双线梯形与编织双环上使用 1500 次 DAgger 和 20 次 PPO，对独立 easy 验证达到 31 胜、1 次僵局。另一组独立种子中，对 easy 为 64/64 胜；对 normal 为 57 胜、7 负，正常完赛率 100%，总样本取胜率 89.1%。动作报告显示最后一次 PPO 采样中等待 23.9%、派兵 72.9%、停流 3.1%，覆盖 8 个指令源和 69 个目标格。

直接以较大学习率切换 normal 课程发生灾难性遗忘：初始验证总样本取胜率 93.8%，训练后降至 18.8%，但初始最佳模型因门禁保护没有被覆盖。随后跳过重复模仿、把学习率降至 `3e-5` 的短程 PPO 微调保持了能力；最终独立 normal 复测仍为 57 胜、7 负。该模型在完全留出的外环加横梁上为 18 胜、14 次工程预算超限，正常完赛率和总样本取胜率均为 56.2%，仍未通过 80% 泛化门禁。

以上是固定种子的小规模工程基线，不是正式 AI 强度认证，也不是任何地图的平衡或趣味性结论。

历史模型池的链路冒烟使用当前最佳模型同时作为初始化权重和冻结对手，8 个环境完成一次 8 步 PPO 更新。独立 normal 规则验证的初始模型为 16/16 胜，更新后为 15/16 胜且正常完赛率 100%；最佳模型保护保留了更新前检查点。这只证明双边动作、MPS 训练、规则锚点验证与防遗忘保护能够共同运行，不证明一次更新提升了策略。

代表回放冒烟在双线梯形对 easy 的 4 局评测中得到 4 胜；保存的一局胜局以种子 `2100002` 和席位变体重新执行，在第 192 次决策再次得到 `Won`。

双层三角 1v1 投影加入后，旧最佳模型在独立 normal 小样本中对双线梯形和编织双环均为 12/12 胜，对新投影仅 1/12 胜。这说明投影提供了明显不同的策略分布。一次包含 300 次 DAgger 和 3 次 PPO 的低学习率短课程未能学稳新图，并显著损伤旧图能力；三次更新验证均至少有一张图未通过 80% 正常完赛率门禁，因此最佳模型仍保留训练前权重。该记录解释了为什么现在引入抗遗忘锚点，但投影已按当前决策暂停，不能继续参与训练、选模或地图平衡判断。

多难度训练日志现在按“地图 × easy/normal/hard × 席位”分层终局，并报告目标归属与类型。上述短课程的 PPO 样本中，中立目标约占 58%～65%，敌方目标约占 26%～30%，其余主要为友方支援；这些指标描述策略行为，不构成地图趣味性结论。

暂停投影后，以 `main-stage2-low-lr-best.pt` 同时作为初始化权重和冻结 KL 锚点，在两张当前训练图上执行了 5 次低学习率 PPO。第 4 次更新在训练内六因子小样本中为 46 胜、2 负，六个“地图 × 难度”因子均通过双门禁；KL 从约 `0.00012` 平缓增长到峰值约 `0.00323`，没有重现上一课程的整体能力崩塌。随后用另一组固定种子对该检查点执行每因子 32 局、共 192 局确认：175 胜、17 负、正常完赛率 100%、全样本胜率 91.1%；最低因子是编织双环对 hard 的 19 胜、13 负（59.4%），仍通过 50% 门槛。该结果证明抗遗忘链路和六因子选模门禁能够工作，但样本仍只评价当前模型对规则 AI 的能力，不是地图平衡或趣味性结论。

行为指标接入后的另一组独立 192 局基线为 180 胜、12 负、正常完赛率 100%。每张图在三档难度下都只出现两个聚合首攻目标，但进一步按“地图 × 难度 × 席位 × 提交序”条件化后，所有因子都只有一个固定首攻，平均条件熵为 0；换线代理率约为 0.3%～1.7%。困难对手下，双线梯形有 56.2% 对局出现反攻，编织双环为 78.1%，但这只说明对抗压力提高了收复失地的行为。当前模型会覆盖约 11～19 个不同进攻目标，却仍缺少同条件下的开局多样性，因此高胜率不能被解释为已经学会多种战略。

可控多策略试验现已把策略编号写入模型、检查点、正交环境分配、验证、行为报告和回放。旧单策略检查点可无损加载为策略 0，新增策略用确定性微小编码打破对称；训练还支持只更新策略向量的适配器模式。一次四策略适配器课程的训练内最佳点为 92 胜、4 负、正常完赛率 100%；随后用新种子独立评测 192 局为 185 胜、7 负、正常完赛率 100%，所有“地图 × 难度 × 策略”因子均通过 50% 胜率门槛。模型强度与可控训练链路因此通过，但多策略行为门禁未通过：6 个地图与难度组合中没有稳定不同的主开局；相对同条件基准，主动压制、中立扩张和关联铺路的意图命中平均只变化 `+1.7/-0.9/+1.5` 个百分点。该检查点只能称为强模型和多策略骨架，不能称为四种成熟打法。

行为报告曾因 4:4 平票的首攻按插入顺序选出第一名，虚报一个分化组合。现规定主开局必须有唯一最高票；平票只能记为“无稳定主开局”。任何策略意图比例都必须与同地图、同难度的策略 0 基准配对报告，不能用孤立百分比制造提升。

统一策略 V6 不再训练压制、扩张或铺路等显式策略编号。第一项实验把当前 17 通道与相邻决策的 17 通道变化量拼接；虽然训练内门禁达到 97.9%，但同种子独立 192 局只有 176 胜，低于 V5 的 184 胜，因此该观察结构保留为实验开关，不进入游戏。该结果说明新增记忆机制也必须先证明独立收益，不能因为结构更复杂就默认升级。

第二项实验保持单一 17 通道策略，把 PPO 采样温度降到 `0.2`，让训练围绕当前高分动作有限探索。非法动作必须在合法 logits 缩放后再屏蔽；直接把极小掩码值除以低温会溢出并产生 NaN。修复后训练轨迹累计 34 胜、4 负，最佳点位于第 4 次更新。用未参与训练和选模的同一组种子比较，V6 在两张训练图、三档规则 AI 的 192 局为 188 胜，优于 V5 的 184 胜；正常完赛均为 190 局。严格留出的外环横梁上，V6 为 76 胜、18 负、2 次工程预算超限，优于 V5 的 66 胜、21 负、9 次预算超限，但 hard 因子仍只有 14/32 胜，因此外环横梁仍不进入游戏支持列表。

随后权威规则补齐了中立据点 2.5/s 恢复与动态击穿成本，规则 AI 也改为按兵流速度、行军恢复、沿途防御、在途双方兵力和中间据点截留判断可行性，并把后方驻军分段补到前哨。旧 V6 对最终规则 AI 的独立 96 局基线为 39 胜、57 负：easy 31/32，normal 8/32，hard 0/32。此前 188/192 的结果只对旧规则对手有效，不能继续作为当前强度结论。

V7 战术实验把观察扩为 22 通道：新增每格恢复/产能、双方对最终目标的在途投入以及归一化坐标，并以全图池化上下文修正源点与目标评分。动作边界只开放可负担的相邻前沿、必要的己方据点支援、停流和等待；整段不可负担时由前沿逐格推进。在线 DAgger 还加入跨整局阶段的蓄水池回放，修复“学到中后盘便遗忘开局”的问题。最终口径按整段都能保证的 15/s 基础吞吐估算，不把高驻军初段的大波次外推到整场。对最终规则 AI 的独立 48 局小样本中，它对两张训练图的 easy 为 16/16；normal 为 5 胜、11 次预算超限，且 5 胜全部来自编织双环；hard 为 0 胜、9 负、7 次循环。所有样本重复指令率均为 0，证明无效连续派兵约束生效，但逐地图×难度发布门禁未通过。因此游戏中明确标为“V7·战术实验”，保留 V5/V6 供真人比较，不得称为正式升级模型。

V8 强化实验先修正奖励排序：旧环境把僵局、循环和预算超限记为 `-0.5`，而失败为 `-1`，会诱导模型把拖延当成更优结果；三类未收束终局现改为 `-1.1`。随后以 V7 为初始化和冻结 KL 锚点，只对 normal/hard 执行 30 次低学习率 PPO，采样温度 `0.3`，训练内最佳为 update 25。用未参与训练和选模的同一组种子各评测 V7/V8 96 局：easy 都是 32/32；normal 从 V7 的 14/32 提升到 V8 的 20/32，预算超限从 18 降到 12，其中双线梯形 `3→5`、编织双环 `11→15`；hard 均为 0/32。总胜场由 46 提升到 52，证明强化阶段对 normal 收官有独立收益且没有遗忘 easy，但 hard 因子仍未通过，因此游戏中只标为“V8·强化实验”，不替换或删除 V5/V6/V7。

V9 先修复训练动作边界而不是继续盲调 PPO。V7/V8 虽禁止重复同一兵流，却允许活动源每秒改派不同目标；独立报告中每局出现约 200～800 条指令，实际绕过了等待和蓄兵约束。现规定普通进攻与战略补给只能从空闲源发起，活动源必须先停流再换线，只有受攻击且低于 40% 上限的己方据点允许紧急转防；安全前线只有在它确为通往非己方目标的首个中转据点、低于 80% 上限且后方源至少有 30 兵时才能接收补给。V9 从 V8 初始化，用 hard 老师、`normal:hard=1:2` 状态采样、48 环境、600 次 DAgger、`3e-5` 学习率、`0.2` 模型采样概率和指令权重 8 刷新策略。

同地图、同难度、同种子的独立 96 局中，V9 在当时“只开放相邻前沿”的边界下为 easy 32/32、normal 16/32、hard 0/32，总计 48 胜；冻结 V6 为 30/32、9/32、0/32，总计 39 胜。随后加入“己方补给目标安全达到 80% 却不停流”的即时负奖励，并把 PPO 采样温度提高到 `0.6`、学习率提高到 `2e-5`：停流率从约 `0.02%～0.08%` 提升到 `0.63%～1.48%`，验证正常完赛率从 66.7% 提到 70.8%，但总胜率从 50.0% 降到 45.8%，所以最佳模型仍保留强化前的 V9 模仿检查点。V10 扩展可承担长程动作后，冻结 V9 在当前共享边界下复测为 32/32、13/32、0/32。hard 仍为 0，不能替代真人试玩结论，也不删除 V5～V8 对照项。

V10 的首要修复不是继续调 PPO，而是消除规则老师与战术动作边界的矛盾。旧边界会把完整成本可承担、无中间据点、但尚未紧邻己方领土的长程进攻裁成等待；紧急增援经过己方枢纽时也会被静默裁掉。现只以完整成本、源是否空闲和中间据点截留判断非己方目标，防守则优先选择能直达受威胁据点的最近前线，无力直达时再向第一个友方枢纽分段补给。两张训练图的 8 组四向同种子控制中，hard 老师经战术边界对 normal/hard 从 `3/8、0/8` 恢复为 `8/8、4/8`，与未加边界完全一致。

在新契约上，hard DAgger 候选首次取得 hard 胜局，但单独使用会遗忘 easy 收官；平衡微调可到 hard 9/32，却仍损伤 normal。由于这些检查点都从 V9 连续微调，最终将 V9 与平衡候选做 50% 浮点权重插值，得到 V10。原控制 96 局为 easy 32/32、normal 28/32、hard 23/32，总计 83 胜；完全未参与插值筛选的另一组 48 局为 16/16、16/16、11/16，总计 43 胜。时间差分候选仅 14/96，加深卷积候选 23/96，均未导出。V10 因此作为“长程实验”进入游戏并保留 V5～V9，但自动胜率仍不能替代真人试玩或证明地图平衡。

V11 不再读取规则老师动作。第一代正式联盟从 V10 初始化，混合 V6/V8/V9/V10 等 6 个冻结历史对手，采用随机对手动作、纯终局奖励和冠军淘汰门槛，完成 196,608 次训练决策与 556 局终局。候选对 V10 的晋级赛为 35 胜、17 负、12 次循环；独立 144 局规则对照为 136 胜、8 负且全部完赛，V10 同种子为 130 胜、8 负、5 次循环、1 次预算终止。三张图 hard 为 40/48，其中完全留出的外环横梁为 15/16。Rust 只对 V11 使用固定种子的温度 0.5 采样，V5～V10 的确定性行为保持不变。

## 7. 真人试玩埋点

游戏侧默认开启 1v1 真人数据采集，每局在 `training/telemetry/` 写一份 schema v1 JSONL；设置 `EASYWAR_TELEMETRY=0` 可关闭，也可将环境变量直接设为其他输出目录。采集点位与训练契约共用同一个 Rust 编码器，记录决策前 22 通道观察、固定动作编号、玩家级合法动作、战术候选动作、实际玩家/AI 命令、每秒等待样本和终局。观察以非零 `[index, value]` 对稀疏保存，不改变数值精度。

规则 AI 与神经 AI 的命令在 SimTick 决策链尾、下一 tick 应用前记录，因此状态与动作严格同拍。埋点只负责留存证据，不自动参与训练：只有 `actor_role=player` 的命令可作为真人示范候选；周期等待需下采样，AI 动作必须单独用于对照诊断，并继续执行按整局划分的训练/验证隔离，避免同一局状态泄漏。

消费链路分为三层。第一层用 `easywar-app --verify-telemetry <jsonl>` 同时播放原始玩家和 AI 指令，要求复现胜者与终局时间；第二层由 `human_replay.py` 恢复稠密观察，并由 `train_human_shadow.py` 按整局隔离训练“玩家影子”；第三层才让新候选对冻结玩家影子进行纯终局自博弈。开放循环录像只能作为复现证据，不能直接当作会应变的对手，因为模型改变局势后，按固定时间播放的源据点可能已经失守。玩家影子负责把录像变成状态条件策略，候选还必须同时通过旧冠军和规则基线门禁，防止只学会针对某位玩家或某一种开局。

## 8. 当前门禁与下一步

- 已实现冻结旧模型的策略 KL 锚点，并把锚点路径和系数写入可恢复训练状态；
- 已实现逐“训练图 × 规则难度”的验证矩阵，每个因子必须同时达到正常完赛率和全样本胜率门槛才可参与最佳模型选择；
- 已记录并可回放复验首攻目标、首次出手、同源换线代理、反攻、目标覆盖与重复指令，并按地图、对手、席位、提交序和终局分层；
- 显式多策略已退出正式模型路线；相关输入、适配器和报告只保留为实验工具，游戏内 V6 固定使用统一策略 0；
- 时间差分观察尚未通过独立同种子门禁，不得导出到游戏；下一轮记忆研究应先改进跨种子稳定性；
- 加入规则老师动作准确率的独立验证集，区分等待类和指令类；
